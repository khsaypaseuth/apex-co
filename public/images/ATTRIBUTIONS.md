# Image Attributions

## These are stock photographs, not Apex work

Every photograph below is licensed stock. None of them shows an Apex site, an
Apex project, or Apex personnel. They illustrate the **kind** of work each
capability covers, which is why the alt text describes the scene generically
and never names Apex, a client, or a location the source does not confirm.

Two rules the set follows, and any replacement should keep:

1. **No photograph appears under a project name.** Project cards and project
   detail headers use drawn schematics (`components/ProjectThumb.tsx`). A photo
   sitting beneath "115/22 kV Substation, Savannakhet" reads as a picture of
   that job; a photo in a capability hero does not.
2. **Location claims match the source.** Where a source carries no location
   tag, the alt text stays location-generic and must never be captioned as
   Laos or Vientiane. Only `patuxai-victory-gate-vientiane.jpg` is
   location-confirmed and may be named.

Replacing these with real Apex site photography is the single biggest visual
upgrade available to this site.
