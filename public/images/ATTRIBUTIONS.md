# Image Attributions

## Replace these with real Apex site photography

Every photograph below is licensed stock, kept as a **placeholder**. None of
them shows Apex work, an Apex site, or Apex personnel, and the alt text is
written so that none of them claims to. They are here so the page compositions
hold together until Apex supplies its own photography.

Two rules the current set follows, and any replacement should keep:

1. **No photograph is presented as a project.** Project cards and capability
   heroes use drawn schematics (`components/ProjectThumb.tsx`), not photos.
   Putting a stock substation on a project card would assert work Apex did not
   do.
2. **Location claims match the source.** Where a source has no location tag,
   the alt text stays location-generic and must never be captioned as Laos or
   Vientiane.

All images are from [Pexels](https://www.pexels.com/license/) under the Pexels
License (free for commercial use, no attribution legally required — attributed
here as project policy). Downloaded 2026-07-10 and 2026-07-11 via the Pexels
CDN, resized to hero ≤ 2400px / banners ≤ 1600px, all files ≤ 600KB. Where a
portrait original was cropped to landscape, the crop was done by the Pexels CDN
(`fit=crop`).
